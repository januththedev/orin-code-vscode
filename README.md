# Orin Code for VS Code

Orin AI chat in your editor. No API keys — sign in with your orinai.org account.

- Sidebar chat with Deep reasoning toggle
- `Orin: Explain selection` on any code
- Token in VS Code secret storage, device-flow sign-in

Build: `npm install && npm run compile` → `out/extension.js`.
Package: `npx vsce package` → install the `.vsix` (Extensions → Install from VSIX).

No Telegram integration in this extension — chat and code only.
